# ⚠️ Deprecated — Epsilon Library

**The Epsilon library and its companion files are deprecated and no longer maintained.**

Earlier releases of HySEALab were built around `epsilon.py`, a Python library for visualizing and analyzing Tsunami-HySEA results, together with setup scripts and a user manual. This approach has been replaced by the collection of **self-contained Jupyter Notebooks** organized in the [preprocessing](../preprocessing/), [processing](../processing/) and [postprocessing](../postprocessing/) folders of this repository.

These files are kept **for reference only**:

| File | Description |
|------|-------------|
| `epsilon.py` | Legacy visualization library |
| `epsilon_config_example.py` | Configuration template for custom paths |
| `Manual_Usuario_Epsilon.ipynb` | Interactive user manual (Spanish) |
| `Setup_HySEALab.ipynb` | Automatic setup notebook |
| `setup_hysealab.sh` / `setup_hysealab.py` | Setup scripts (bash / Python) |
| `SETUP_USUARIO.md` | Setup guide for HySEALab cluster users (Spanish) |
| `ACTUALIZAR_COMPUTE.md` | Update instructions for compute-2-0 users (Spanish) |

No bug fixes, new features or support will be provided for these files. Please migrate to the notebook collection.
